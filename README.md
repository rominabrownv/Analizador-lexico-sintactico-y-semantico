# Analizador-lexico-sintactico-y-semantico
Proyecto enfocado al desarrollo de un analizador léxico, semántico y sintáctico en el lenguaje LUA

## Ejecución

Pasa la ruta del algoritmo y el usuario como argumentos para que el programa no los solicite:

```bash
python probar.py test/algoritmoDePrueba1.lua usuarioGit
```

Si omites alguno de los argumentos, el programa solicitará el dato faltante.
